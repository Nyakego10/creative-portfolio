# My Creative Portfolio

## About

This is a simple portfolio website built using React. It shows my projects and allows users to search for projects and add new ones.

## Features

- View my projects.
- Search for projects.
- Add new projects.
- Simple design that works on different screen sizes.

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Vitest

## How to Run

1. Download or clone the project.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the link shown in the terminal.

## Testing

Run `npm run test:run` to test the project.
